# 甜蜜日记 Love Diary 💝

> 一款为情侣量身打造的专属微信小程序 —— 记录爱的每一刻。

## ✨ 功能模块

| 模块 | 功能说明 |
| :--- | :--- |
| 🏠 甜蜜首页 | 情侣卡片 + 相爱天数、每日情话（可切换）、4 个快捷入口、今日菜单、纪念日倒计时、经期状态、最近时光 |
| 🍳 爱的菜单 | 菜品分类/搜索/排序/收藏、设为今日菜单、🎲 随机选菜（带滚动抽奖动画）、难度星级展示 |
| 🎀 纪念日 | 分类筛选（恋爱/生日/回忆/其他）、倒计时徽章（7天内高亮闪烁）、进度条、年度第N年、重要标记、长按操作 |
| 🌸 身体小助手 | 阶段大卡片、日历视图（经期/预测/排卵期/排卵日/今日标记）、关键日期3卡、健康小贴士、周期/经期天数可自定义配置、历史记录 |
| 💝 我们的时光 | 时间线视图（按月分组+节点连线）、相册网格视图、年份筛选、翻页次数统计、心情+照片+地点、查看/编辑/删除 |
| ⚙️ 我的 | 情侣卡片（点击编辑昵称）、4种主题切换、恋爱纪念日设置、数据统计、JSON 导出/导入备份、重置、分享、关于 |

## 🎨 设计风格

**恋爱糖系风 · Sweet Lovers Aesthetic**
- 主色：蜜桃粉 `#FF6B9D` + 薄荷绿 `#A8E6CF` + 柠檬黄 `#FFD93D` + 薰衣草紫 `#C9B1FF`
- 视觉：大圆角卡片、柔和多层阴影、渐变文字、浮动爱心装饰、多层微动画
- 交互：stagger 卡片入场、pulse 心跳、bounce-in 弹窗、点击缩放

## 🚀 快速开始

### 1. 导入项目
1. 打开**微信开发者工具**，点击「导入项目」
2. 目录选择 `love-diary/` 文件夹
3. AppID：可以选择「测试号」体验，上线时替换为自己的小程序 AppID

### 2. 本地体验
- 所有数据默认使用 `wx.setStorageSync` 存放在本地，无需后端即可完整体验
- 首次启动会自动初始化示例数据（6道菜 / 4个纪念日 / 2条时光）

### 3. 开启云开发（可选，用于多端同步 & 情侣共享）
1. 在微信开发者工具中点击顶部「云开发」按钮开通
2. 创建环境，复制**环境 ID**
3. 打开 [app.js](file:///C:/Users/user/AppData/Roaming/TRAE%20SOLO%20CN/ModularData/ai-agent/work-mode-projects/6a7ec5c73f9d92d20f587cd3/love-diary/app.js#L14)，将第 14 行 `env: 'your-env-id'` 替换为真实环境 ID
4. 上传并部署 `cloudfunctions/` 目录下的所有云函数（每个子目录右键 → 上传并部署：云端安装依赖）
5. 在云开发控制台 → 数据库，新建以下集合（权限选「仅创建者可读写」）：
   - `menus`、`anniversaries`、`moments`、`periods`、`couple_info`、`theme_info`

## 🛠️ 可扩展功能建议

项目结构已预留这些功能的钩子，你可以在现有基础上继续拓展：

- 💌 **情侣绑定**：我的 → 生成情侣码 → 对方输入 → 共享一条数据空间
- 📱 **消息订阅**：纪念日 7 天前提醒、经期前提醒、排卵日提醒
- ☁️ **照片云存储**：使用 `wx.cloud.uploadFile` 将时光照片上传云存储
- 🏷️ **更多菜品标签**：可以接入外部菜谱 API 丰富菜单
- 🔮 **经期健康分析**：周期不规则时给出提示，多周期对比图
- 🎵 **背景音乐**：首页可设置情侣专属 BGM
- 🎯 **互动任务**：每日打卡（例如"今天抱了吗💑"）累积积分

## 📤 发布上线流程

### 步骤 1：准备
- 注册小程序账号：[mp.weixin.qq.com](https://mp.weixin.qq.com) → 选择「小程序」注册（个人主体即可）
- 完成「微信认证」（个人主体 30 元/年，企业 300 元/年）
- 绑定开发者：管理后台 → 成员管理 → 开发者 → 添加

### 步骤 2：填写小程序资料
- 小程序名称：2-16字，不可与已重复（例如「甜蜜情侣日记」）
- 小程序简介：如"情侣专属记录工具，菜单/纪念日/经期助手/时光相册"
- 服务类目：选择「工具」→「备忘/效率」或「生活服务」→「综合生活服务」
- 头像：上传 1:1 正方形 Logo

### 步骤 3：上传版本
1. 微信开发者工具右上角点击「上传」
2. 填写版本号 `1.0.0`、项目备注（"初版发布：5大核心功能"）
3. 上传成功后，登录 [管理后台](https://mp.weixin.qq.com) → 版本管理 → 开发版本
4. 点击「提交审核」

### 步骤 4：等待审核
- 审核通常 **1-3 天**，首次可能较慢
- 常见被拒原因：
  - 无用户协议/隐私政策弹窗：建议在首页 onShow 加一个授权弹窗（含《用户协议》和《隐私政策》链接）
  - 内容过于简单：可以再加一些功能，或在描述里写清楚定位
  - 涉及敏感词：名字和文案里避免"打卡""签到""预测"等可能需要资质的词（经期预测改为"经期记录助手"更稳妥）

### 步骤 5：正式发布
- 审核通过后，登录后台点击「发布」，小程序正式上线 🎉
- 可在「版本管理」中对体验版、线上版进行灰度发布、回滚
